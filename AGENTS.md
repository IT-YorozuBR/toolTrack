# Contexto do projeto

No início de qualquer sessão sobre este repositório, leia `CONTEXTO_PROJETO.md` na raiz —
é o resumo de especificações, domínio, mapa de páginas e pendências para retomar o
trabalho sem reconstruir contexto do zero.

Depois de qualquer mudança não-trivial (nova feature, mudança de schema, nova server
action, nova convenção, decisão de escopo ou correção de bug com causa raiz não óbvia),
atualize `CONTEXTO_PROJETO.md` (seção relevante) antes de terminar a sessão. Para
investigações/features grandes e multi-sessão, prefira um arquivo dedicado
`CONTEXTO_<ASSUNTO>.md` e deixe só um resumo curto em `CONTEXTO_PROJETO.md` apontando
para ele. Mudanças triviais (estilo, texto de label, refactor sem mudança de
comportamento) não precisam ser registradas.
